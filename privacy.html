プライバシーポリシー

Yachiyo は作者個人が自分の PC で使うためのアプリで、作者以外の利用者はいません。

Google ユーザーデータの利用

  • Google Calendar API の読み取り専用の権限（calendar.events.readonly）だけを使います。
  • 取得するのは予定の開始時刻・終了時刻・状態だけです。予定のタイトル、場所、説明、参加者は取得しません。
  • 取得した時刻は、予定の件数と時刻を音声で読み上げるためだけに使います。
  • 返事の文章を作るため、日付ごとの予定の件数と時刻だけを Google Gemini API に送ることがあります。それ以外の第三者には提供しません。
  • ログイン用のトークンと動作ログは利用者の PC にだけ保存し、外部のサーバーには保存しません。
  • 広告には使いません。なお Gemini API の無料枠では、送った内容（件数と時刻）が Google のサービス改善に使われることがあります。

削除

PC 上のトークンを削除するか、Google アカウントの「サードパーティ製のアプリとサービス」からアクセスを取り消すと、いつでも利用を止められます。
